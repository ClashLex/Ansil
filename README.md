## 🛠️ Stack & Features

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack, Static Export)
- **Library**: [React 19](https://react.dev/) & [TypeScript](https://www.typescriptlang.org/)
- **Design System**: Liquid Glassmorphism, Custom Cursor, Audio Feedbacks, Snake Game mini-app
- **Deployment**: Automatic GitHub Actions deploy to GitHub Pages

<br/>

## 🎮 Interactive Features

- **Liquid Glassmorphism**: Dynamic backdrop blur with interactive glow.
- **Embedded Snake Game**: Classic canvas Snake game with sound synthesis & high score saving.
- **Audio Feedback**: Web Audio API synthesized haptic tick sounds on click.

<br/>

## 💻 Local Development

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Static production build
npm run build
```
